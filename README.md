# Kade32 Team - publieke demo (geen personeelsdata)

Deze repository is uitsluitend voor de interactieve demonstratie van Kade32 Team. De demo gebruikt fictieve personeelsgegevens en slaat alleen in de browser lokale testwijzigingen op. **Vul geen echte personeelsgegevens, uren of wachtwoorden in.**

## Publiceren via GitHub Pages

1. Maak een nieuwe publieke repository `kade32-team-demo` in je eigen GitHub-account.
2. Plaats deze `index.html` in de root van de standaardbranch `main`.
3. Ga naar Settings > Pages > Build and deployment > Deploy from a branch > `main` / `/(root)` > Save.
4. Open `https://<GITHUB-GEBRUIKERSNAAM>.github.io/kade32-team-demo/`.
5. Klik op 'Bekijk de demo'; rechtsboven kun je van testrol wisselen.

De demo is **niet** het afgesloten echte medewerkersportaal. Daarvoor zijn later een afzonderlijke backend, veilige accounts en rechtencontrole nodig.
